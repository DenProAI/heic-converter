## Зачем это нужно

iPhone снимает фото в формате **HEIC** — он лёгкий и качественный, но почти ни один сервис (включая многие CMS, мессенджеры и фотобанки) его не понимает. Стандартное решение — загружать фото на онлайн-конвертер. Минусы:

- 🚫 Твои личные фото уходят на чужой сервер
- 🚫 Водяные знаки и лимиты на бесплатных тарифах
- 🚫 Долго при пакетной обработке
- 🚫 Нужен интернет для каждой конвертации

Этот конвертер решает всё это: **вся обработка происходит в твоём браузере**. Файлы никуда не уходят. Работает офлайн после первой загрузки страницы.

## Возможности

- ✅ **Drag & drop** или клик для выбора файлов
- ✅ **Пакетная обработка** — десятки файлов сразу, параллельно по 3
- ✅ **ZIP-архив** одной кнопкой для всех конвертированных файлов
- ✅ **Настройка качества** JPEG (60–100%)
- ✅ **Превью** результата с показателем экономии размера
- ✅ **Тёмная тема** в travel-эстетике
- ✅ **100% приватность** — нет бэкенда, файлы остаются на устройстве
- ✅ **Один файл** — `index.html`, который можно скачать и использовать офлайн

## Как пользоваться

### Вариант 1: Через GitHub Pages (онлайн)

Перейди по ссылке выше — конвертер открывается сразу.

### Вариант 2: Скачать и использовать офлайн

1. Скачай файл [`index.html`](./index.html)
2. Открой его двойным кликом
3. Готово — работает без интернета (после первой загрузки CDN-библиотек)

### Вариант 3: Установить как PWA

Открой конвертер в Chrome → в адресной строке нажми иконку «Установить» → появится иконка как у обычного приложения.

## Технологии

- **[heic2any](https://github.com/alselawi/heic2any)** — декодирование HEIC в браузере
- **[JSZip](https://stuk.github.io/jszip/)** — упаковка в ZIP-архив
- **Vanilla JS** — без фреймворков, без сборки, один файл

## Локальная разработка

Никакой сборки не требуется — это статичный HTML.

```bash
git clone https://github.com/USERNAME/heic-converter.git
cd heic-converter
# Открой index.html в браузере или запусти любой локальный сервер:
python3 -m http.server 8000
# Открой http://localhost:8000
```

## Известные ограничения

- **Размер файлов:** браузер может тормозить на десятках фото по 5+ МБ. Для огромных партий лучше серверное решение
- **EXIF:** библиотека `heic2any` не сохраняет EXIF (дата, гео-метки) в выходном JPEG. Если EXIF критичен — используй [ImageMagick](https://imagemagick.org) или [`pillow-heif`](https://github.com/bigcat88/pillow_heif) на сервере
- **Многокадровые HEIC:** Live Photos с iPhone содержат несколько кадров — конвертируется только первый
